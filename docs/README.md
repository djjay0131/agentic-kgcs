# `docs/` — project artifacts and derived views

This directory holds project and domain deliverables, external material,
and derived views: product and API documentation, project/domain technical
specifications and reference material, vendor and third-party
specifications, external proposals, research sources, PDFs, diagrams,
datasets, and published sites generated from `llm/`.

Nothing here governs how this repository is operated. Governance, policy,
decisions, plans, and every other artifact that controls how this
repository is governed, planned, remembered, reviewed, or operated lives
under `llm/`.

The rule, the decision procedure for choosing between the two trees, and
the closed list of exempt tool-contract paths are stated in:

- `CLAUDE.md` — the tool-facing statement, bound to this repo's paths
- `llm/governance/governance-delta.md` §Repository Layout — what this repo declares
- agentic-governance `llm/governance/adr/0001-llm-control-plane-docs-data-plane.md`
